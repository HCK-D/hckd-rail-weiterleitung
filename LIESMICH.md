# hckd-rail.ch → railbase.ch

Die alte Adresse von RailBase. Jede Seite hier leitet auf die gleiche Seite bei https://railbase.ch weiter
und nimmt dabei einmal die gespeicherte Sammlung, Sichtungen und Einstellungen mit.

- `index.html` und `404.html` sind gleich: GitHub Pages zeigt `404.html` für jede alte Seite (z. B. `/re-460.html`).
- `sw.js` ersetzt den alten Offline-Speicher der App und meldet ihn ab.
- `CNAME` verbindet dieses Repository mit hckd-rail.ch.

Die Website selbst liegt im Repository `hckd-rail`.
